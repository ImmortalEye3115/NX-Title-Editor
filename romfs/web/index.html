    About

    NX Title Editor

    This app works by using icon sysmodules such as sys-tweak ↗ and sys-ticon ↗ to change the icons, names, authors and version numbers of titles installed on the Switch.

    These modules look for JPG and INI files within the TitleID folders for each app in "/atmosphere/contents/" and then replace the displayed icons and game info with the contents of those folders.

    This app hosts a small web server on the Switch that can be connected to from a web browser, where you can then replace the selected title's default icons with custom ones from SteamGridDB ↗, your local files or a URL. You can also modify the title's name, author and version number. This data is then converted into the correct format expected by icon sysmodules and sent to the Switch, where it is automatically saved in the correct folder structure.

    All changes can only be seen after a reboot.
